# HWP 5.0・HWPX の取り込み

デスクトップ版とブラウザー版の「開く」で HWP 5.0 または HWPX を選ぶと、編集可能な Word 文書として取り込まれます。保存時は別の DOCX ファイル名を指定してください。

通常の圧縮・非圧縮の HWP 5.0 と、ZIP パッケージ形式の HWPX が対象です。本文、主要な文字・段落書式、結合セルを含む表、用紙設定、埋め込みの PNG・JPEG・GIF・BMP を読み込みます。暗号化・配布用・DRM 付き HWP 5.0、図形・数式・外部リンク画像・複雑な浮動配置には対応していません。フォントの代替、改行規則、表の改ページにより、元の文書と版面が異なる場合があります。

본 제품은 한글과컴퓨터의 한글 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다.
