# HWP 5.0・HWPX の取り込み

デスクトップ版とブラウザー版の「開く」で HWP 5.0 または HWPX を選ぶと、編集可能な Word 文書として取り込まれます。保存時は別の DOCX ファイル名を指定してください。

通常の圧縮・非圧縮の HWP 5.0 と、ZIP パッケージ形式の HWPX が対象です。本文、主要な文字・段落書式、結合セルを含む表、用紙設定、埋め込みの PNG・JPEG・GIF・BMP を読み込みます。暗号化・配布用・DRM 付き HWP 5.0、数式・外部リンク画像・グループ化された図形には対応していません。フォントの代替、改行規則、表の改ページにより、元の文書と版面が異なる場合があります。

段落番号と文字の箇条書きは、DOCX の編集可能なリストとして取り込みます。ヘッダー・フッターは奇数／偶数ページの指定を反映します。ページ番号は自動更新されるフィールドに変換し、セクション先頭での番号の再設定も読み込みます。画像による箇条書きや、セクション途中での番号の再設定は対象外です。

行内画像と浮動画像の位置・回り込みを読み込みます。HWPX では画像の回転・反転に加え、基本的な長方形・楕円の塗りと線、図形内のプレーンテキストを取り込めます。輪郭に沿う回り込みは矩形の輪郭で近似します。HWP のベクター図形、図形内の文字書式、複雑な浮動配置には対応していません。

본 제품은 한글과컴퓨터의 한글 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다.
