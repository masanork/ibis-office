# 機械可読性チェック

表計算の「ツール > 機械可読性チェック」では、編集中の結合セル・非表示行列・数式・機種依存文字や全角英数字を確認候補として表示します。文字の分類は Harunobu の L1-08 を参考にしていますが、シート全体の文字列を対象とし、表領域や文字コードによる合否は判定しません。私用文字（PUA）は、表示や意味の共有に注意が必要な候補として別に表示します。IVS は私用文字として扱いません。この候補は Harunobu の判定や得点に影響しません。

デスクトップ版では XLSX・XLSM および保存済み CSV・TSV の L1、L1–L2、L1–L3 をローカルで検査できます。検査エンジンと入力形式の判定はアプリ内で実行し、Python や Git の実行環境を必要としません。AI 補完はオフで、結果は JSON または CSV で保存できます。複数ファイルの検査では、ファイル横断の L3-07 も実行します。スコアは未判定ルールを除いた Harunobu の参考値です。

検査エンジンは [Harunobu 0.2.2](https://github.com/digital-go-jp/machine_readability_rule/tree/88014ff9cfe685d4e0e5f24a2d4d2e021ca3fd9f) を基に Rust で実装しています。入力内容の識別には Rust 版 Magika を使用します。本家との比較テストには開発時の Python を使用しますが、アプリの実行時には使用しません。

## 制限

- 保存先が決まっている XLSX・XLSM の未保存の編集は、検査開始時点の一時的なシリアライズ結果で検査します。元ファイルは保存・変更しません。結果は編集後に再検査してください。入力中のセルは確定する必要があります。CSV・TSV の未保存の編集は、元のテキスト形式を保って検査するため保存が必要です。
- 内容を正確に再現できない一部の Excel データやメタデータはエラーとして扱います。全ファイルで Harunobu と同じ結果になることはまだ確認できていません。
- 完全検査はデスクトップ版で提供します。Web 版の完全検査は未提供です。
- 複数ファイル結果からセルへの直接移動はできません。
- AI 補完は未対応です。AI なしで判定できない項目は未判定と表示します。
- 表領域は自動推定します。複雑な表やタイトル・注釈では誤検出があり、公式の適合証明ではありません。詳しくは [Harunobu の既知の制限](https://github.com/digital-go-jp/machine_readability_rule/blob/88014ff9cfe685d4e0e5f24a2d4d2e021ca3fd9f/docs/guides/limitations.md) を参照してください。
- 対応するセル位置は選択できます。非表示シートや未対応の位置表記は一覧に表示しますが、直接移動できません。
