# 表記確認機能のデータ出典と設計メモ（調査中）

最終確認: 2026-11-16。これは配布許諾の確定や法的判断ではない。
実際に組み込む各ファイルの版、URL、ハッシュ、ライセンス本文、加工者と加工内容を
データ更新時に記録し、配布物でも必要な表示を行う。候補は原文を保持して提示し、
確認なしに置換しない。候補の一致は同一人物を意味しない。

| 対象 | 候補と確認事項 | 状態 |
| --- | --- | --- |

soroe は調査対象として参照した。soroe のコード、辞書、テストを製品にコピーする場合は
それぞれのライセンスと由来を別途確認する。再実装したというだけで第三者データの条件は
消えず、この作業をクリーンルーム開発と称しない。

日付の試作では年/月/日の順で、2桁年の 00〜29 を 2000〜2029、30〜99 を
1930〜1999 と推定して明示する。この境界は暫定で、入力の種類によって適否が異なる。
