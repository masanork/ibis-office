# Keyboard Shortcuts

[[help/index|← Back to Help Index]]

On macOS, `⌘` is Command and `⌥` is Option. On Windows, Linux, and browsers, use `Ctrl` for `⌘` and `Alt` for `⌥`.

## File Operations

| Action | Shortcut |
| --- | --- |
| New Document | `⌘N` |
| Open File | `⌘O` |
| Save | `⌘S` |
| Save As | `⇧⌘S` |
| Print | `⌘P` |
| Close File | `⌘W` |
| Quit App (Desktop) | `⌘Q` |

## Editing & Formatting

| Action | Shortcut |
| --- | --- |
| Undo | `⌘Z` |
| Redo | `⇧⌘Z` / `Ctrl+Y` |
| Cut / Copy / Paste | `⌘X` / `⌘C` / `⌘V` |
| Select All | `⌘A` |
| Find / Replace | `⌘F` / `⌘H` |
| Bold / Italic / Underline | `⌘B` / `⌘I` / `⌘U` |
| Insert Link | `⌘K` |
| Insert Comment | `⌥⌘M` |
| Clear Formatting | `⌘\` |

## View, Window & Help

| Action | Shortcut |
| --- | --- |
| New Window | `⌘⇧N` |
| Split View | `⌥⌘S` |
| Zoom In / Out / Reset | `⌘+` / `⌘-` / `⌘0` |
| Search Menus | `⌥/` |
| Keyboard Shortcuts (this page) | `⌘/` |
| Settings | `⌘,` |
| Word Count (Tools) | `⇧⌘C` |

> [!NOTE] Menu Search (`⌥/`)
> Press `⌥/` (`Alt+/`) at any time to search and run any menu command by keyword.
