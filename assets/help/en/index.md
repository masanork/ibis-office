# soraneDocs / ibisOffice Help

**soraneDocs / ibisOffice** is an integrated document workspace for viewing and editing Markdown (notes, Marp slides, Workbook spreadsheets, Lawtext) and Office documents (DOCX / XLSX / PPTX / JTD / XDW / VSDX, etc.) with bidirectional Split editing.

You can always open the latest help from the **Help** menu, and you can also keep a copy inside the `help/` directory of your GitHub Vault or local Vault to search, link, and experiment with syntax directly.
