# Workbook Markdown 記法

[[help/index|← ヘルプ目次に戻る]]

YAML フロントマターに `type: workbook`（または `<!-- xlsx-sheet: シート名 -->`）を指定すると、Markdown を **表計算ワークブック（XLSX 互換）** として開き、数式の再計算やセル編集を双方向 Split で行えます。

## 1. 基本例（数式と複数シート）

```markdown
---
type: workbook
title: 四半期売上計画
---

# 売上計画

| 項目 | Q1 | Q2 | 合計 |
| --- | ---: | ---: | ---: |
| ライセンス | 120000 | 150000 | =SUM(B2:C2) |
| サポート | 40000 | 45000 | =SUM(B3:C3) |
| 合計 | =SUM(B2:B3) | =SUM(C2:C3) | =SUM(D2:D3) |

# シート2: サマリー

| 指標 | 値 |
| --- | ---: |
| 年間見込 | =売上計画!D4*2 |
```

## 2. 主なルール

- **H1 見出し (`# シート名`)** または **`<!-- xlsx-sheet: シート名 -->`**: 新しいワークシートの開始位置になります。
- **数式 (`=...`)**: セル内に `=SUM(...)`, `=AVERAGE(...)`, `=IF(...)`, シート間参照 `=シート名!A1` などを書くと、そのまま計算エンジンで評価されます。
- **列のアライメント (`:---`, `:---:`, `---:`)**: 数値列を `---:` で右寄せにすると見やすく整理されます。
- **XLSX 書き出し**: 編集したワークブックは **ファイル > エクスポート** や **名前を付けて保存** から `.xlsx` として保存できます。
