# キーボードショートカット一覧

[[help/index|← ヘルプ目次に戻る]]

※ macOS では `⌘`（Command）、Windows / Linux / ブラウザでは `Ctrl` に読み替えてください。`⌥` は Option / Alt です。

## ファイル操作

| 操作 | ショートカット |
| --- | --- |
| 新規作成 | `⌘N` |
| ファイルを開く | `⌘O` |
| 保存 | `⌘S` |
| 名前を付けて保存 | `⇧⌘S` |
| 印刷 | `⌘P` |
| ファイルを閉じる | `⌘W` |
| アプリを終了（デスクトップ） | `⌘Q` |

## 編集・書式

| 操作 | ショートカット |
| --- | --- |
| 元に戻す (Undo) | `⌘Z` |
| やり直し (Redo) | `⇧⌘Z` / `Ctrl+Y` |
| 切り取り / コピー / 貼り付け | `⌘X` / `⌘C` / `⌘V` |
| すべて選択 | `⌘A` |
| 検索 / 置換 | `⌘F` / `⌘H` |
| 太字 / 斜体 / 下線 | `⌘B` / `⌘I` / `⌘U` |
| リンクを挿入 | `⌘K` |
| コメントを挿入 | `⌥⌘M` |
| 書式をクリア | `⌘\` |

## 表示・ウィンドウ・ヘルプ

| 操作 | ショートカット |
| --- | --- |
| 新しいウィンドウ | `⌘⇧N` |
| 分割（Split） | `⌥⌘S` |
| 拡大 / 縮小 / 100% | `⌘+` / `⌘-` / `⌘0` |
| メニューを検索 | `⌥/` |
| キーボードショートカット（この画面） | `⌘/` |
| 設定を開く | `⌘,` |
| 文字数カウント（ツール） | `⇧⌘C` |

> [!NOTE] メニュー検索 (`⌥/`)
> 「あの機能どこだっけ？」というときは `⌥/`（Alt+/）を押すと、すべてのメニューコマンドをキーワードで即座に検索・実行できます。
