# Markdown 基本・拡張記法

[[help/index|← ヘルプ目次に戻る]]

soraneDocs / ibisOffice は CommonMark + GitHub Flavored Markdown (GFM) をベースに、Callout、脚注、数式、Wiki リンク、Mermaid などの拡張記法に対応しています。

## 1. 見出しと段落

```markdown
# 見出し 1 (H1)
## 見出し 2 (H2)
### 見出し 3 (H3)
```

見出しにカスタムアンカーを付ける場合は `{#custom-id}` のように記述できます。

## 2. 文字装飾

| 記法 | 表示例 | 用途 |
| --- | --- | --- |
| `**太字**` | **太字** | 強調 |
| `*斜体*` | *斜体* | イタリック |
| `~~取り消し線~~` | ~~取り消し線~~ | 削除・修正箇所 |
| `` `インラインコード` `` | `code` | コマンド・識別子 |
| `==ハイライト==` | ==ハイライト== | 蛍光ペン強調 |
| `H~2~O` / `x^2^` | H~2~O / x^2^ | 下付き・上付き文字 |

## 3. リストとタスクリスト

```markdown
- 箇条書き 1
  - ネストした項目
1. 番号付きリスト 1
2. 番号付きリスト 2

- [x] 完了したタスク
- [ ] 未完了のタスク
```

実際の表示：
- [x] 完了したタスク
- [ ] 未完了のタスク

## 4. テーブル（表）

```markdown
| 項目 | 左寄せ | 中央寄せ | 右寄せ |
| :--- | :--- | :---: | ---: |
| 予算 | A案 | ○ | 120,000 |
| 実績 | B案 | △ | 98,500 |
```

列の区切り行の `:` の位置で左寄せ・中央寄せ・右寄せを指定できます。

## 5. 引用と Callout（コールアウト）

通常の引用は `>` を使います。先頭行に `[!NOTE]` や `[!TIP]`、`[!WARNING]`、`[!IMPORTANT]`、`[!CAUTION]` を書くと Callout ブロックになります。

```markdown
> [!NOTE] 参考情報
> 補足説明や背景知識をわかりやすく強調できます。

> [!WARNING] 注意事項
> 上書き保存や破壊的操作の前に確認したい内容を記載します。
```

> [!TIP] Callout の種類
> `NOTE` / `TIP` / `IMPORTANT` / `WARNING` / `CAUTION` に対応しています。

## 6. コードブロック・脚注・区切り線

コードブロックは ```` ```言語名 ```` で囲みます。水平線は `---`（空行で挟む）です。

脚注は `[^1]` で参照し、文書の末尾などで `[^1]: 脚注の説明` と記述します[^1]。

[^1]: これが脚注のサンプルです。Word (`.docx`) への変換時にも脚注として往復保持されます。

## 7. 数式（LaTeX / Math）

インライン数式は `$...$`、ディスプレイ数式は `$$...$$` で囲みます。

```markdown
三平方の定理は $a^2 + b^2 = c^2$ です。

$$
E = mc^2
$$
```
