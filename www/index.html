DOCUMENT GALLERY

実際の文書で、確かめる。

図形や工程表を組み合わせた資料と、数式・グラフを使った分析ブック。実際に公開されているファイルでお試しください。表示や編集には、元のアプリと異なる部分があります。

POWERPOINT · PPTX

官民データ連携のアクションプラン

複数の図形、接続線、図表や工程表を含む14枚の資料。ロゴ入り背景を除いた加工版です。一部の図表は画像です。

サンプルをひらく ↗

出典：デジタル庁「AI時代の官民データの整備・連携に向けたアクションプラン」（概要）を Sorane Docs が加工（ロゴ入り背景を除去）。

EXCEL · XLSX

まちなかの居心地の良さを測る分析ツール

複数シートに数式と50個のグラフを含む記入例。「結果_概要結果」や「結果_詳細結果」シートでグラフを見られます。

出典：国土交通省「まちなかの居心地の良さを測る指標（改訂版ver.1.1）」分析ツール（記入例）

ICHITARO · JTD

ABOUT SORANE DOCS

いつもの文書に、
新しい選択肢を。

Sorane Docs は、ibisOffice をもとに開発している文書アプリです。ブラウザですぐに文書を開き、日本語を含むさまざまな文書に触れられます。

ファイル形式や機能によっては、表示・編集に制限があります。大切な文書は元のファイルを残してお使いください。
