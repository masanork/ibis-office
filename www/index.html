ABOUT SORANE DOCS

いつもの文書に、
新しい選択肢を。

Sorane Docs は、ibisOffice をもとに開発している文書アプリです。ブラウザですぐに文書を開き、日本語を含むさまざまな文書に触れられます。

ファイル形式や機能によっては、表示・編集に制限があります。大切な文書は元のファイルを残してお使いください。
